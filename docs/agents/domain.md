# Domain docs

## Before exploring

- Glossary: Read `CONTEXT.md` for the repository vocabulary.
- Architecture decisions: Read relevant ADRs from the `alpacon-handbook`
  repository.
- Missing documentation: Proceed silently when no relevant glossary entry or
  ADR exists.

## Layout

This repository uses one domain context with `CONTEXT.md` at its root. ADRs are
not stored locally.

## Vocabulary

Use the canonical terms from `CONTEXT.md`. Do not substitute terms listed under
`_Avoid_`.

## ADR conflicts

Surface any conflict with an `alpacon-handbook` ADR instead of silently
overriding it.
