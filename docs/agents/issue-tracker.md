# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for
`alpacax/alpacon-mcp`. Use the `gh` CLI for all operations.

## Conventions

- Create an issue: Use `gh issue create`.
- Read an issue: Use `gh issue view <number> --comments` to include comments.
- List and filter issues: Use `gh issue list`.
- Comment on an issue: Use `gh issue comment`.
- Apply or remove labels: Use `gh issue edit`.
- Close an issue: Use `gh issue close`.

## Pull requests as a triage surface

PRs as a request surface: no.

## Skill behavior

- Publish to the issue tracker: Create a GitHub issue.
- Fetch a ticket: Read the GitHub issue and its comments.
